# Skill: /add-ingredient-tool

Add or update the ingredient lookup tool (search + API + panel).

## Phases
1. **Search** — Ensure SearchBar.jsx works with Fuse.js index
2. **Panel** — Ensure IngredientPanel.jsx shows all data sections
3. **API** — Ensure api/server.js serves all 3 endpoints
4. **Wire** — Connect search → 3D selection → panel display
5. **Validate** — Test search with sample ingredients, verify API responses

## Usage
```
/add-ingredient-tool
```
