# docs/archive

Planning and design documents from the build (March–August 2026), moved
here at the v1.0.0 freeze. Historical: they describe intent at the time
of writing, not necessarily what shipped. The live specs that still match
the app are one level up in `docs/`.

- `VISION.md`, `UX_SURVEY.md` — early product direction and UX audit
- `PAIRING_FORMULA_DESIGN.md`, `new_pipeline_may_2.md` — pairing-score design notes
- `GNN_UPGRADE.md` — molecular model upgrade plan (see `.claude/.chemdataset-status.md` for what actually happened)
- `RALPH-SPEC-flavor-profiles.md` — the un-built Flavor Profiles card spec (see `BACKLOG.md`)
- `PROMPT.md` — an early autonomous-loop prompt
- `agent-runs/` — plan/prd/prompt files from each agent run that built a
  subsystem (ingredient cleanup, cocktail and sauce curation, harness)
