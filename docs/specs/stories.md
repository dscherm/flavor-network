# stories as-built specs

## STORIES-1 — Dish stories and photos from Wikipedia on recipe, sauce, cocktail and wine cards

Cards carry an 'About this dish / sauce / drink / wine' section: the first 1-2 sentences (<=300 chars) of the English Wikipedia article plus its lead photo when the photo is freely licensed on Wikimedia Commons. Build-time only: scripts/build_dish_stories.mjs (polite User-Agent, ~1 req/s, raw responses cached in .cache/dish-stories/, deterministic re-runs) writes public/data/dish_stories.json (271 KB, keyed recipes/sauces/cocktails/wines, _meta with source, licences, date, counts). Matching (src/data/dishStoryMatch.js, pure): overrides (scripts/dish_story_overrides.json: title, null to skip, or {title, photo:false}), then exact title, sentence case, title + qualifier, then opensearch; a page is accepted only if not a disambiguation page, food/drink by description or first sentence (own title excluded; album/film/place/distillery descriptions rejected), and the title plausibly names the item (search hits may be more specific, never less, so riffs do not inherit their parent). Photos: lead image must be a Commons file (enwiki-hosted = skipped) with LicenseShortName CC0 / public domain / CC BY / CC BY-SA and a real artist; thumbnails hotlinked from upload.wikimedia.org (500px bucket). Loader src/data/dishStories.js (lazy, cached, fail-safe, retries after failure) + component src/components/DishStory.jsx (fixed aspect box, loading=lazy, alt 'Photo of x', chalk frame, credit 'Text: Wikipedia (CC BY-SA) · Photo: artist, licence' all linked) mounted in Cookbook RecipeDetail, SauceLab and CocktailLabV2 LabNodeCard children, WineLab card. README data-licence table row added. Report: docs/dish-stories.md.
