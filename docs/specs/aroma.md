# aroma as-built specs

## AROMA-1 — Experiment: do model-written aroma tags predict good pairings?

449 Flavor Bible answer-key ingredients tagged (1-5 of 32 aroma tags, intensity 1-3) by three model agents told to describe each ingredient alone (data/experiments/aroma_tags_449.json, instructions alongside). Pre-registered test (scripts/evalAromaTags.mjs): aroma-tag cosine AUROC 0.512 vs molecular GNN 0.527 on all 100,576 pairs; adds nothing to co-occurrence on observed pairs (0.630 -> 0.630). FAIL. Exploratory (scripts/exploreAromaTagCombos.py, held-out ingredients): tag COMBINATIONS reach 0.598 when trained on Flavor Bible labels, but 0.510 when trained on recipe co-occurrence — the signal is learned from the Flavor Bible itself, which the project cannot ship. Conclusion: no shippable aroma pairing signal; do not tag the remaining 3,891 for pairing. Tags may still serve as descriptive 'smells like' labels.

## AROMA-2 — Second-opinion check: every disagreement with the distilled profiles reviewed

scripts/checkAromaAgreement.mjs compares each line of the aroma table with the second source (flavor_profiles_distilled.json, through the curation layer's name resolution) and prints: agreement on the strongest aroma, top-two overlap, table lines with no counterpart, and every disagreement with both sides shown and whether the second source's entry is chef-sourced. Read every disagreement (40 at the time of the spec). For each: correct the table line with a reason when the second source is right (likely: chilies, gin, vermouths), or record it in data/review/aroma-accepted.json with a reason when the table is right or the difference is only the missing axes (those are re-checked in AROMA-3). The check becomes part of npm run audit:data: a table edit that creates a new unreviewed disagreement fails --check. Do not tune against the held-back third of the blind key.

## AROMA-3 — Eleven aroma axes: toasty, nutty, earthy, smoky and savory join the six

The aroma axes become fruity, floral, green, woody, spice, fatty, toasty (roasted, caramel), nutty, earthy, smoky, savory (meaty, marine, fermented). Every line of src/data/flavorAromas.js is re-read and given values on the new axes where they apply; ingredients that had no aroma because their aromas had no home get real lines (fish sauce, anchovy, soy sauce, miso, parmesan and aged cheeses, coffee and coffee liqueur, cocoa and chocolate, nuts and nut milks, mushrooms, beets, root vegetables, smoked paprika, bacon, mezcal and peated whisky, caramel and brown sugar, toasted sesame, stocks and seared-meat bases). Values that were standing in for a missing axis are moved (coffee liqueur from woody to toasty, almond milk from woody to nutty). flavorAroma.js, the shared profile helpers, axis labels, colours (eleven distinct, readable on slate, not colliding with the six taste colours), balancing pairs, per-axis pages and boost / temper all cover eleven. The second-opinion check is re-run with the full 17-word mapping; accepted disagreements that were only 'missing axis' must now agree or be re-decided.

## AROMA-4 — Charts kept readable with eleven aromas (interim rule; the redesign is CHART-1); docs; final measurement

With six tastes and eleven aromas a full chart has seventeen bars. One rule, the same on every surface (Recipe Notebook overview and flavor map, invent panels, Cookbook radar, shared page, browser and server share cards): show the strongest bars above a stated floor, tastes and aromas in their own groups, with a stated maximum per group (for example four and four on a card, more on the full Recipe Notebook page), and 'show all' where there is room. Per-axis pages and boost / temper work for every axis. Server and browser cards re-rendered and looked at for a drink, a sauce and a dish. docs/flavor-profile.md gains 'Aromas, second pass' with all scores stage by stage, what the second source is and is not (mostly AI-written; a second opinion, not ground truth), and what is still wrong by item. BACKLOG.md records the two deferred pieces with enough detail to pick up: using the second source for ingredients outside the table, and aromas created by cooking method. CLOSEOUT.md unreleased entry and README updated. share-cards.json regenerated.
