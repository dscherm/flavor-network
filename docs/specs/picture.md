Port the prototype's filter into src/data/chalkFilter.js as pure functions over pixel arrays: chalkify({ data, width, height }, settings) returning the same shape, CHALK_DEFAULTS (weight 5, detail 13, shading 110, colour 200, grain 5), CHALK_RANGES (weight 0.6-10, detail 0-16, shading 0-200, colour 0-300, grain 0-100), and prepare(image) that scales to 1080 px on the long side and stretches contrast. ## PICTURE-3 — Storing pictures: with a saved item and with a shared copy

Saved items gain picture: { kind: 'icon'|'chalk', icon?, v }. A chalk picture is stored as its own document profiles/{uid}/pictures/{itemId} ({ data (base64), mime, w, h, updatedAt }), never inside the profile document; deleting the item deletes its picture. A shared copy stores sharedPictures/{shareId} ({ data, mime, w, h, owner, createdAt }) written with the share, and shared/{id} carries picture: { kind, icon? } only. firestore.rules: profiles/{uid}/pictures/{id} readable and writable by that user only, size-capped (data string length under 210,000); sharedPictures/{id} get by anyone, list by nobody, create by the signed-in owner within the cap and only alongside their own share id, delete by the owner, and unreadable to others once shared/{id}.removed is true. Offline or failed picture writes never block saving the item or creating the link; the item is saved without the picture and the user is told in one line. The original photo is never sent anywhere.

## PICTURE-6 — Focus: a sixth slider that fades the background of a chalk picture to bare slate

Add a `focus` setting to src/data/chalkFilter.js: 0 (the default) draws the whole photo exactly as today; raising it keeps a centred oval of the picture and fades every chalk mark outside it (lines, shading, colour fill and grain) smoothly to the bare slate ground, the oval tightening as the value rises. CHALK_DEFAULTS.focus = 0 and CHALK_RANGES.focus = 0-100. The oval follows the crop (square or landscape) and the fade is smooth, with no visible ring. Pure, deterministic, no DOM, no network, as the rest of the filter. RecipePicture.jsx's Adjust panel gains a sixth labelled slider, 'Focus', with live preview and Reset like the other five. At focus 0 the output must be byte-identical to PICTURE-1's for the same input and settings (the prototype-parity test keeps passing unchanged). Stored pictures need no migration: the setting is not stored, only the finished picture.
