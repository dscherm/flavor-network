## 3. Data layer

### 3.1 Schema for `cocktail_codex_v2.json`

```ts
interface CocktailCodexV2 {
  _meta: {
    generatedAt: string;
    model: "kmeans-k6";
    silhouette: number;       // 0.183
    near_hit_rate: number;    // 0.90
    far_hit_rate: number;     // 1.00
    composite_score: number;  // 0.633
    n_cocktails: number;      // 441
    n_families: 6;
    n_subclusters: number;    // 12
  };
  families: Family[];           // 6 entries
  subclusters: SubCluster[];    // 12 entries
  cocktails: CocktailV2[];      // 441 entries
}

interface Family {
  id: 0 | 1 | 2 | 3 | 4 | 5;
  name: string;                 // "Sour Family"
  cultural_root: string;        // "Daiquiri"
  math_root: string;            // "Casino" (centroid-nearest IBA, kept for transparency)
  color: string;                // hex
  signature: {
    dominant_slots: { slot: string; ratio: number }[];  // [{slot:"spirit", ratio:0.31}, ...]
    layer_mix: { top: number; middle: number; bass: number };
    size: number;
  };
  exemplars: string[];          // 5 prototypical IBA cocktails
}

interface SubCluster {
  id: string;                   // "2.1"
  family_id: 0 | 1 | 2 | 3 | 4 | 5;
  size: number;
  signature: { dominant_slots: { slot: string; ratio: number }[] };
  exemplars: string[];          // 3-5 examples
}

interface CocktailV2 {
  name: string;
  canonical: string;
  family_id: 0 | 1 | 2 | 3 | 4 | 5;
  subcluster_id: string;        // "2.1"
  is_root: boolean;             // true for the cultural_root cocktail
  iba_official: boolean;
  iba_category?: "unforgettables" | "contemporary" | "new_era";
  ingredients_raw: { raw: string; name: string; amount_ml?: number; measure?: string }[];
  recipe_text: string;
  glass: string | null;
  garnishes: string[];
  build_method: string | null;
  ice_format: string | null;
  aeration: string | null;
  feature_vector: number[];     // 31-dim, for cosine similarity
}
```

### 3.2 Build script

`proDataset/cocktails_v2/scripts/09-emit-codex-v2.cjs` (new):

```
Inputs:
  proDataset/cocktails_v2/raw/corpus_v3.json
  proDataset/cocktails_v2/data/cocktail_clusters.json
  proDataset/cocktails_v2/data/cocktail_engineering.csv
  proDataset/cocktails_v2/raw/local_syrups.json

Outputs:
  public/data/cocktail_codex_v2.json
  public/data/cocktail_syrups.json
```

Logic:
1. Load corpus + clusters + engineering tags.
2. Apply the cultural Root override map:
   ```js
   const CULTURAL_ROOT = {
     0: "Mai Tai",
     1: "Tom Collins",
     2: "Daiquiri",
     3: "Old Fashioned",
     4: "Negroni",
     // 5: keep Paloma (math Root, per user choice)
   };
   ```
3. Apply family name + color overrides.
4. For each cocktail:
   - Look up its cluster + subcluster from `cocktail_clusters.json`
   - Mark `is_root = true` for the cocktail named in `CULTURAL_ROOT[family_id]`
     (the math root is preserved in `families[].math_root`)
   - Attach engineering tags from `cocktail_engineering.csv`
5. Compute feature_vector per cocktail (re-run feature pipeline from
   notebook, store as 31-dim array — used for cross-family similarity).
6. Emit syrups separately to `cocktail_syrups.json`.

### 3.3 Validation tests

- Schema is well-formed (every cocktail has a family_id ∈ [0,6))
- Every family has exactly one cocktail with `is_root = true`
- Cultural roots match the override map

  * Negroni and Boulevardier in same family
  * Daiquiri and Margarita in same family
  * Old Fashioned and Sazerac in same family
  * (Manhattan and Rob Roy in different families — by design)
  * Negroni and Daiquiri in different families
- Syrups (24 entries) NOT in main cocktail array

## 4. UI changes — `CocktailLab.jsx`

### 4.1 3D scene re-layout

Current: 7 archetype clusters laid out via Fibonacci-sphere lattice
(`FAMILY_RADIUS = 20`), with subclusters splayed radial-perpendicular.

New: same Fibonacci-sphere pattern, but **6 nodes** instead of 7.
Each cluster's centroid stays on the sphere shell; sub-clusters now
arrange as inner concentric rings within each family's "disc."

Key changes in `cocktailCodex.js`:
```js
- const FAMILIES = parseCodexFamilies(rawCodex.clusters);  // 7
+ const FAMILIES = loadV2Families(codexV2);                // 6
```

```js
- function placeFamilyOnSphere(idx, total=7) { ... }
+ function placeFamilyOnSphere(idx, total=6) { ... }
```

### 4.2 Cocktail node visuals

| State | Treatment |

| IBA-official | Standard size, family color |
| Codex-tagged | Standard size, slight tint |

### 4.3 Sub-cluster visuals

Render sub-clusters as **inner orbits** within each family disc. Each

## 5. Similarity layer — `cocktailGraph.js`

### 5.1 Current behavior

`cocktailCodex.js:169-190` computes ingredient-keyword Jaccard
similarity within each family for the "Similar cocktails" panel.
Edges created for similarity ≥ 0.18.

### 5.2 New behavior

Replace with feature-vector cosine similarity:

```js
function cocktailSimilarity(a, b) {
  // Both have feature_vector: number[31]
  return cosine(a.feature_vector, b.feature_vector);
}
```

Edge thresholds:
- **Strong** (≥ 0.85): same sub-cluster + high cosine
- **Medium** (0.70-0.85): same family, different sub-cluster
- **Weak** (0.55-0.70): cross-family but high feature similarity (the
  "interesting bridge" connections — Manhattan ↔ Rob Roy lives here)

Edges below 0.55 are not rendered.

## 8. Risks

1. **3D layout aesthetic.** Going from 7 to 6 spheres slightly changes
   the visual rhythm. May want to manually tune sphere radii to maintain
   pleasing density.
2. **Sub-cluster naming.** We're shipping numeric sub-cluster IDs. If
   users find that confusing, a follow-up v1.1 could hand-name the 12
   sub-clusters.
3. **Math vs cultural Root contradicts the data display.** A user who
   inspects the JSON will see `cultural_root: "Negroni"` AND
   `math_root: "Tipperary"` for cluster 4. This is intentional but
   might confuse first-time readers. Add a tooltip or doc comment.
4. **Old archetype URLs / bookmarks.** If anyone deep-linked into the
   old Cocktail Lab (unlikely), those links break. Acceptable since
   this is a single-user app pre-launch.
5. **Feature vector size in JSON.** 31 dims × 441 cocktails = ~14k
   floats added to `cocktail_codex_v2.json`. ~120 KB extra payload.
   Acceptable but worth flagging.
