Four ways to set the type

The same Negroni card and the same recipe-builder question in each pairing. Nothing here is chosen. A chalk hand sets titles, and a steady face sets everything you read or press.

A

The Caveat the app already uses for titles, with a text serif like a printed bistro menu, so the hand stays rare and the reading is calm.

Caveat for titles, Newsreader for everything else

Negroni

Stirred, bittersweet, bright orange at the end

  • 1 ozgin
  • 1 ozCampari
  • 1 ozsweet vermouth
  1. Stir with ice.
  2. Strain over a large cube.
  3. Finish with an orange peel.

What is the main ingredient?

Chicken thighs, a pork shoulder, a whole fish: any ingredient works.
